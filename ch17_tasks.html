Tasks 待辦

Tasks 是 Nextcloud 的待辦清單，和行事曆整合、能跨裝置同步。讀完這章，你能建立待辦、設期限與優先度，並讓待辦出現在行事曆裡。

待辦清單也自己管

待辦事項用一般 app 記，換裝置就散掉。Tasks 把待辦存在 Nextcloud，和 Calendar 共用同一套資料，能設期限、優先度，還能跨裝置同步，事情不漏接。

本章任務：建一個待辦清單與項目、設期限與優先度、了解和行事曆的整合。

Tasks 和 Calendar 是一家

Tasks 和 Calendar 底層共用 CalDAV：一個「清單」其實對應一本日曆。所以待辦能和行事曆一起同步、一起顯示。

概念說明
清單（List）一組待辦，對應一本日曆
待辦（Task）單一事項，可設期限、優先度、子任務
與行事曆整合有期限的待辦會顯示在 Calendar

五步用起 Tasks

  1. 打開 Tasks

    從 Apps 選單點「Tasks」。左側是清單。

  2. 建立清單

    新增清單（例如「家事」「工作」），選顏色區分。

  3. 加待辦

    在清單裡輸入待辦名稱按 Enter；點進去可設細節。

  4. 設期限與優先度

    在待辦裡設到期日、優先度（高／中／低），可加子任務與備註。

  5. 完成打勾

    做完把待辦打勾，會移到已完成，需要時可回顧或還原。

和行事曆連動：設了到期日的待辦，會出現在 Calendar 對應的那本日曆裡，一眼看到今天要做什麼。

跨裝置同步

  • 用 CalDAV 網址在手機的待辦／行事曆 app 加帳號，待辦雙向同步。
  • Android 可用支援 CalDAV 的待辦 app；iOS 提醒事項也能透過 CalDAV 整合。
  • 桌面上和 Calendar 一起同步，不必分開設定。

Tasks 常見卡關

  1. 找不到 Tasks

    Tasks 是獨立 app，可能未啟用，請管理員啟用（第 21 章）。

  2. 待辦沒出現在行事曆

    確認待辦有設到期日；沒期限的不會顯示在日曆時間軸。

  3. 手機同步不到

    檢查 CalDAV 帳號設定（建議用 App 密碼），確認指到正確清單。

  4. 子任務展不開

    點待辦進入詳情頁查看子任務；清單視圖可能只顯示主任務。

Tasks 常見問題

Tasks 和 Deck 該用哪個？
Tasks 適合個人／清單式待辦、和行事曆整合；Deck 適合看板式專案協作（第 14 章）。可以並用。
待辦能分享嗎？
能，分享對應的清單（日曆）給站內帳號，適合家庭共用家事清單。
和 iOS 提醒事項能同步嗎？
可透過 CalDAV 整合，設定較進階，參考官方文件。
完成的待辦會刪掉嗎？
不會，移到已完成，可回顧或還原。
可以設重複待辦嗎？
可以設重複規則（每天／每週），適合固定家事。
