讓 AI agent 會整理你的雲端

Skill 是教 AI agent 一項專門手藝的「說明書」。裝上檔案管理相關的 skill，你的 agent 就會照最佳做法幫你整理檔案、盤點分享、顧備份。這本收錄精選 skill、生態工具與安裝速查（2026-08 調查）。

Skill 是什麼，為什麼要裝

Skill 可以想成「給 AI 的 SOP 手冊」：一份 SKILL.md 寫明「遇到什麼任務、照什麼步驟、用什麼工具、注意什麼」。agent 讀到它就多會一件事，做法穩定、不會每次憑空亂猜。

對 Nextcloud 來說，常見 skill 場景：批次整理檔案、盤點與收回分享、使用者配額稽核、備份盤點、行事曆/聯絡人維護。裝了對應 skill，這些事你只要下指令，agent 就照 SOP 做。

怎麼裝（3 分鐘版）

前提：你的 agent 要支援 skill（例如 Pi Agent、Claude Code 等）。裝法概念相同：把 skill 資料夾放進 skills 目錄。
  1. 找到 skill 的 GitHub repo，記下網址。
  2. 在 agent 的 skill 安裝面板貼上 repo 網址或選目錄。
  3. 安裝後確認 skill 出現在可用清單（或系統提示裡）。

精選檔案管理 skill（家庭視角）

依「家庭雲端管理」會遇到的真實需求，整理值得一找的 skill 類型。星數以 GitHub 現況為準（2026-08），安裝前務必確認 repo 仍在維護。

檔案批次整理

分類：整理 · 觸發 WebDAV

依規則（時間、副檔名、大小）把檔案分類到資料夾，附重複偵測與乾跑模式（先回報再動手）。

分享稽核

分類：安全 · 觸發 OCS API

掃描所有分享，標出無密碼、無期限、公開的風險項，並可批次補密碼或收回。

使用者與配額稽核

分類：管理 · OCS Provisioning API

盤點帳號狀態、群組、配額使用率，找出停用仍佔空間或超額的帳號。

備份與還原演練

分類：維運 · 資料庫＋檔案

盤點備份狀態、產出還原步驟、用 rclone 規畫異地備份。

行事曆／聯絡人維護

分類：整理 · CalDAV/CardDAV

去重聯絡人、匯出備份、盤點久未更新的日曆。

名稱與星數以 GitHub 現況為準：生態變化快，本頁列的「類型」是穩定需求，實際 repo 名稱與星數請安裝前重新查證。

生態工具（不只 skill）

除了 agent skill，Nextcloud 生態還有這些常用工具，值得一起認識：

工具用途何時用
nextcloud/server官方主 repo查文件、看更新、回報 issue
桌面 client / 手機 App官方同步 client日常檔案與照片同步（第 18、19 章）
rclone支援 WebDAV 的同步工具異地備份、批次搬檔
nextcloudcmd命令列同步腳本化、伺服器間同步
DAVx5（Android）CalDAV/CardDAV 同步手機行事曆與聯絡人同步
Home Assistant 整合把 Nextcloud 接進 HA行事曆觸發自動化、備份丟雲端（附錄 C）

相容性須知

  • 版本對齊：Nextcloud API 隨版本演進（本教學為 v33），skill 若寫死端點，升級後可能要更新。
  • 權限：多數操作需要對應權限或 admin；skill 要能拿到 App 密碼／token 才有用。
  • App 依賴：行事曆／聯絡人／Deck 相關 skill 依賴對應 App 已啟用（附錄 A）。

安全守則

永不讓 skill 直接刪除：任何操作走「先回報 → 你確認 → 再執行」，刪除一律先進回收桶。
用 App 密碼、不外流：裝第三方 skill 前，檢查它會不會把密碼、檔案路徑傳到外部。來路不明的不要裝。
乾跑優先：批次操作先要求 skill 產出「將影響 N 個項目」的預覽，確認無誤才放行。

SKILL.md 規格速查

想自己寫一個 Nextcloud skill，核心就是一份 SKILL.md：

---
name: nextcloud-share-auditor
description: 掃描 Nextcloud 分享、標出風險項並可批次收回，附乾跑模式
---
# 用途
用 OCS API 盤點所有分享，找出無密碼／無期限／公開的風險項。

## 步驟
1. 呼叫 OCS Shares API 取得所有分享
2. 標記風險項，產生「預覽清單」（影響 N 筆）
3. 等使用者確認後才批次補密碼／設期限／停用
4. 回報結果與例外

## 安全
- 永不直接刪檔，只調整分享設定
- 批次操作前必須先回報影響範圍
- 一律用 App 密碼

詳細規格請參考你使用的 agent 的 skill 文件。

常見問題

Skill 和 App／整合有什麼不同？
App 是「有介面的程式」，整合是「兩個服務串接」，Skill 是「教 AI 怎麼做」的說明書，裝了讓 agent 自己會操作。
裝錯 skill 會弄壞我的雲端嗎？
有可能。所以安全守則最重要：只裝可信來源、永遠先乾跑、刪除先進回收桶、用 App 密碼。
我能自己寫 skill 嗎？
能。照上面的 SKILL.md 骨架，把「步驟」和「安全」寫清楚即可。
哪個 skill 最值得先裝？
「分享稽核」與「重複偵測＋整理」最有感，能立刻降低風險、釋放空間。
