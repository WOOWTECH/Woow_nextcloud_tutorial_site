WoowTech · Nextcloud API/WebDAV 提示詞庫

用一句話，指揮你的雲端

透過 Nextcloud 的 WebDAV、OCS API 與 CalDAV/CardDAV，把下面這些自然語言提示詞交給 AI agent，讓它幫你整理檔案、盤點分享、管使用者、顧備份。每一條都能複製，改成你家的說法就能用。

這本是什麼

Nextcloud 有開放的 API：WebDAV（檔案讀寫）、OCS API（分享、使用者、capabilities）、CalDAV/CardDAV（行事曆、聯絡人）。把這些包成 MCP 工具或用腳本呼叫後，AI agent 就能用自然語言幫你操作。這本是「你要對 agent 說的話」的範本庫。

前提：需要環境已接好 Nextcloud API 存取（App 密碼）。第一次使用前，先確認 agent 能連到你的 Nextcloud。

怎麼用這些提示詞

複製 → 貼進 agent → 把佔位詞換成真實說法 → 送出。關鍵是講清楚「範圍」與「要做什麼」，避免誤動整庫。

安全習慣：任何「刪除、批次修改、分享」類動作，都先要求 agent 回報「將影響 N 個項目」讓你確認，再執行。一律用 App 密碼、不要用主密碼。

檔案整理

盤點大檔
用 WebDAV 掃描我的檔案，列出前 20 大的檔案（含路徑與大小），先不要刪，讓我決定。
整理資料夾
把「下載」資料夾裡超過一年沒動過的檔案，整理到「封存/2025」資料夾（先列清單讓我確認）。
找重複
找出內容重複的檔案（用雜湊比對），列出重複組別與可釋放空間，不要自動刪。
依副檔名分類
把某個資料夾裡的檔案依副檔名分到子資料夾（圖片、文件、影片），先給我預覽對照表。
清回收桶
列出回收桶內容與各自佔用空間，計算清空可釋放多少，等我確認再清。

分享盤點

盤點所有分享
用 OCS API 列出我所有的分享：對象、權限、有無密碼與到期日，標出「公開且無密碼」的風險項。
找快過期
列出 7 天內到期的分享連結，讓我決定要續期還是收回。
收回舊分享
找出建立超過 90 天、且是公開連結的分享，列出清單，等我確認後停用。
批次補密碼
把所有沒設密碼的公開分享，補上密碼與 30 天到期（先列出會影響幾個）。
建立分享
幫資料夾「聚會照片」建一個公開分享連結，唯讀、加密碼、7 天到期，回傳連結。

使用者管理（管理員）

盤點帳號
用 OCS API 列出所有使用者：狀態（啟用/停用）、群組、配額與已用空間，標出停用中仍佔空間的。
建立帳號
幫我建一個使用者「爸爸」，加入「家人」群組，配額 50GB，並回傳初始設定資訊（不要在對話貼明碼）。
配額檢查
列出配額使用率超過 80% 的使用者，提醒我可能要加配額或請他們清理。
停用而非刪除
把離開的成員帳號停用（不刪資料），列出被停用的帳號讓我複核。

備份策略

備份盤點
盤點目前 Nextcloud 的備份狀態：資料庫、資料目錄、config.php 各有沒有備份機制，缺口在哪。
還原演練
寫一份 Nextcloud 災難還原步驟：假設伺服器掛了，怎麼從備份把資料庫與檔案還原回來。
rclone 異地備份
規畫用 rclone 透過 WebDAV 把我的 Nextcloud 每日增量備份到另一個儲存，給我設定步驟。
容量預估
依過去一年的成長量，預估多久會用到儲存上限，並建議清理或擴充。

行事曆與聯絡人

匯出通訊錄
透過 CardDAV 把「家人」通訊錄匯出成 vCard 備份一份。
去重聯絡人
找出通訊錄裡疑似重複的聯絡人（同名或同電話），列出待合併清單讓我確認。
建立事件
在「家庭」日曆建一個下週六下午 2 點的事件「大掃除」，提前一天提醒。
盤點日曆
列出我所有日曆與事件數量，標出很久沒更新、可以封存的。

Deck 與協作

建立看板
幫我在 Deck 建一個「搬家計畫」看板，含待辦/進行中/完成三個列表，並加幾張常見任務卡片。
盤點逾期
列出 Deck 裡所有已逾期、未完成的卡片，依看板分組，提醒我處理。
週報
整理本週在 Deck 完成的卡片，做成一份簡短週報。
文件盤點
列出最近 30 天有多人編輯的 Office 文件，方便我掌握協作狀況。

排錯與維運

健康檢查
做一次 Nextcloud 健康檢查：伺服器版本、安全與設定警告、背景工作、儲存，逐項回報與建議。
信任網域
檢查目前的 trusted_domains 設定，確認對外網址有在清單裡，沒有就提示我該加什麼。
背景工作
檢查背景工作（cron）是否正常執行，找出最久沒跑的工作並建議處理。
空間告警
當整體儲存低於 15% 時，列出釋放空間的優先順序（回收桶、重複檔、超額使用者）。

常見問題

提示詞怎麼改才不會誤動整庫？
永遠加「範圍」與「先回報、再執行」兩句。例如「先列出會影響的項目數量，等我確認再執行」。
用什麼認證？
一律用 App 密碼（個人設定→安全性建立），不要把主密碼寫進 agent 或腳本。
找不到某個 API？
Nextcloud 的 WebDAV、OCS、CalDAV/CardDAV 端點在官方開發者文件；不同版本略有差異，先讓 agent 查文件。
能讓 agent 直接刪檔嗎？
建議關掉「直接刪除」，改「移到回收桶＋回報」，多一層保護。
