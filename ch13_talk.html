Talk 聊天與視訊

Talk 是 Nextcloud 內建的聊天與視訊會議。讀完這章，你能開一對一或群組對話、發起視訊會議、分享畫面，全部在自己家的伺服器上進行。

自己家的視訊會議

要和家人、同事即時溝通，通常得用第三方通訊軟體。Talk 讓你在自己的 Nextcloud 裡聊天、開會、分享畫面，訊息與通話資料都在自己家，隱私自己掌握。

本章任務：開一個對話、發訊息、發起視訊通話、了解分享畫面。

對話、通話與檔案

功能說明
一對一對話和單一使用者的私訊
群組對話多人聊天室，可命名、加人
視訊／語音通話在對話裡發起，支援多人與分享畫面
公開對話連結產生連結讓外部訪客加入會議
和檔案整合：對話裡可以直接分享 Nextcloud 的檔案，對方點就能開，不用另外傳。

五步用起 Talk

  1. 打開 Talk

    從 Apps 選單點「Talk」。左側是對話清單。

  2. 開新對話

    按「＋」建立對話，選一位使用者（一對一）或建群組聊天室。

  3. 發訊息

    在下方輸入框打字送出；可貼檔案、提及（@）某人。

  4. 發起視訊通話

    在對話右上角按通話圖示，開始語音或視訊，其他成員可加入。

  5. 分享畫面

    通話中按分享畫面圖示，選整個螢幕或某個視窗，適合簡報與教學。

視訊需要頻寬：多人視訊很吃網路。人多或畫質差時，可關視訊只留語音，或請管理員設定 TURN 伺服器改善連線。

邀請外部訪客

  • 在對話設定產生「公開對話連結」，傳給沒有帳號的人。
  • 可設密碼保護會議連結。
  • 會議結束把連結停用，避免之後有人再進來。
會議連結也是鑰匙：公開會議連結流出，陌生人可能加入。設密碼、開完就停用。

Talk 常見卡關

  1. 通話連不上或一直轉圈

    多半是網路穿透問題，需要管理員設定 TURN 伺服器。先試同網段或改語音。

  2. 對方聽不到我

    檢查瀏覽器的麥克風權限，確認選對輸入裝置。

  3. 分享畫面沒畫面

    瀏覽器要授予螢幕分享權限；部分瀏覽器需在系統設定允許。

  4. 找不到 Talk

    Talk 是獨立 app，可能尚未啟用，請管理員在 Apps 商店啟用（第 21 章）。

Talk 常見問題

訊息會存在哪？
存在你自己的 Nextcloud 伺服器，不經第三方通訊平台。
手機能用 Talk 嗎？
能，有 Nextcloud Talk 手機 App，可收訊息與接通話。
視訊人數上限多少？
依伺服器效能與是否有 TURN／SFU 而定。小型家用建議人數別太多。
可以錄影會議嗎？
部分版本／設定支援錄製，需要額外元件，屬進階，由管理員設定。
外部訪客能看到我其他資料嗎？
不會。訪客只能進入你分享的那個對話／會議，看不到你別的檔案。
