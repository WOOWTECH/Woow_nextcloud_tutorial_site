WebDAV 進階

WebDAV 讓你用系統檔案總管或第三方工具，像操作本機資料夾一樣直接存取 Nextcloud。讀完這章，你能把 Nextcloud 掛載成一個磁碟，或用工具自動化搬檔。

不開瀏覽器也能存取

除了瀏覽器與桌面 client，Nextcloud 還支援 WebDAV——一個檔案存取的標準協定。有了它，你能把 Nextcloud 掛載成系統裡的一個磁碟，或讓備份工具、腳本直接讀寫，適合進階與自動化。

本章任務：找到你的 WebDAV 網址、用系統或工具連線、了解自動化用途。

WebDAV 是什麼

WebDAV 是「用 HTTP 存取遠端檔案」的協定。Nextcloud 給每個帳號一個 WebDAV 網址，格式類似：

https://woowtech-nextcloud.woowtech.io/remote.php/dav/files/你的帳號/
用途怎麼用
掛載成磁碟系統檔案總管連線 WebDAV
第三方工具rclone、Cyberduck、WinSCP 等
自動化腳本／備份工具定期讀寫
一定用 App 密碼：WebDAV 要輸入帳密，務必用「App 密碼」（第 5 章）而非主密碼，並可單獨撤銷。

五步用 WebDAV 連線

  1. 取得 WebDAV 網址

    在 Files 左下角「設定」或個人設定裡，可複製你的 WebDAV 網址。

  2. 建立 App 密碼

    到個人設定「安全性」建立一組 App 密碼，專給 WebDAV 用。

  3. 在系統掛載

    Windows「連線網路磁碟機」、macOS Finder「連接伺服器」、Linux 檔案總管都能連 WebDAV 網址。

  4. 輸入帳號與 App 密碼

    用你的帳號與剛建立的 App 密碼登入。

  5. 像本機一樣用

    掛載後 Nextcloud 變成一個資料夾，可直接拖放、開啟、刪除。

工具與自動化

  • rclone：把 Nextcloud 當一個 remote，做定期備份／同步（附錄 C 有整合方向）。
  • Cyberduck／WinSCP：圖形化拖放搬檔。
  • 腳本：用 curl 或程式庫呼叫 WebDAV，做自動上傳／下載。
掛載 vs 同步：WebDAV 掛載是「直接存取遠端」（不佔本機空間、但要連線）；桌面 client 是「雙向同步」（有本機副本、離線可用）。看需求選。

WebDAV 常見卡關

  1. 登入失敗

    用 App 密碼而非主密碼；確認網址完整、含帳號路徑。

  2. 掛載後很慢

    WebDAV 每次操作都走網路，大量小檔會慢。大批搬移改用桌面 client。

  3. Windows 掛不上

    Windows 內建 WebDAV 對大檔與長路徑支援有限，改用 rclone 或第三方工具較穩。

  4. 中文檔名亂碼

    確認工具用 UTF-8；部分老工具支援不佳，換工具。

WebDAV 常見問題

WebDAV 和桌面 client 差在哪？
WebDAV 是直接存取遠端（不佔本機空間、要連線）；client 是雙向同步（本機有副本、離線可用）。
一定要用 App 密碼嗎？
強烈建議。主密碼到處輸入風險高；App 密碼能單獨撤銷，較安全。
能用 rclone 備份到別的地方嗎？
能。rclone 支援 WebDAV，可把 Nextcloud 內容再備份到其他儲存，反之亦然。
手機能用 WebDAV 嗎？
能，用支援 WebDAV 的檔案 app，但日常還是官方 App 順（第 19 章）。
WebDAV 安全嗎？
走 HTTPS 加密傳輸，安全性取決於你的密碼管理。用 App 密碼並定期檢查已連線裝置。
