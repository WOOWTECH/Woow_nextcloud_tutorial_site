Command your cloud in one sentence

Hand the natural-language prompts below to an AI agent and let it tidy up your files, review your shares, manage users and look after backups through Nextcloud's WebDAV, OCS API and CalDAV/CardDAV. Copy any of them, reword them to match your own home, and they are ready to use.

What this handbook is

Nextcloud has open APIs: WebDAV (reading and writing files), OCS API (shares, users, capabilities) and CalDAV/CardDAV (calendars and contacts). Wrap them as MCP tools or call them from a script, and an AI agent can work them for you in natural language. This handbook is the template library for "what you say to the agent".

Prerequisite: your environment needs Nextcloud API access already wired up (an app password). Before you use these for the first time, confirm that the agent can reach your Nextcloud.

How to use these prompts

Copy → paste into the agent → replace the placeholders with your own wording → send. What matters is being clear about the "scope" and "what to do", so you do not touch the whole library by mistake.

Safe habit: for any "delete, bulk-edit or share" action, make the agent report "N items will be affected" and wait for your confirmation before it runs. Always use an app password, never your main password.

File cleanup

Review the biggest files
Use WebDAV to scan my files and list the 20 largest ones (with path and size). Do not delete anything yet; let me decide. Answer in English.
Tidy up a folder
Move the files in the "Downloads" folder that have not been touched for over a year into an "Archive/2025" folder (list them first so I can confirm). Answer in English.
Find duplicates
Find files with duplicate contents (compare hashes), list the duplicate groups and how much space they would free, and do not delete anything automatically. Answer in English.
Sort by file extension
Sort the files in one folder into subfolders by file extension (images, documents, videos), and show me a preview table first. Answer in English.
Empty the trash bin
List what is in the trash bin and how much space each item takes, work out how much emptying it would free, and wait for my confirmation before you empty it. Answer in English.

Share review

Review every share
Use the OCS API to list all of my shares: who they are shared with, the permissions, whether they have a password and an expiration date. Flag the risky ones that are public with no password. Answer in English.
Find shares expiring soon
List the share links that expire within 7 days, so I can decide whether to extend or revoke them. Answer in English.
Revoke old shares
Find the shares that are public links and were created more than 90 days ago, list them, and disable them after I confirm. Answer in English.
Add passwords in bulk
Add a password and a 30-day expiration date to every public share that has no password (list how many will be affected first). Answer in English.
Create a share
Create a public share link for the folder "Party photos": read-only, with a password, expiring in 7 days, and return the link. Answer in English.

User management (admins)

Review the accounts
Use the OCS API to list every user: status (enabled/disabled), groups, quota and space used. Flag the disabled ones that are still taking up space. Answer in English.
Create an account
Create a user named "dad", add them to the "Family" group, give the account a 50GB quota, and return the initial setup details (do not paste the plaintext password in the conversation). Answer in English.
Quota check
List the users whose quota usage is over 80%, and remind me that I may need to raise their quota or ask them to clean up. Answer in English.
Disable instead of delete
Disable the accounts of members who have left (do not delete their data), and list the disabled accounts so I can double-check. Answer in English.

Backup strategy

Backup review
Take stock of the current Nextcloud backup situation: whether the database, the data directory and config.php each have a backup mechanism, and where the gaps are. Answer in English.
Restore drill
Write a Nextcloud disaster recovery procedure: assume the server is down, and describe how to restore the database and the files from a backup. Answer in English.
Off-site backup with rclone
Plan a daily incremental backup of my Nextcloud to another storage target with rclone over WebDAV, and give me the setup steps. Answer in English.
Capacity forecast
Based on the past year's growth, estimate how long it will be until I hit the storage limit, and suggest what to clean up or expand. Answer in English.

Calendar and contacts

Export an address book
Use CardDAV to export the "Family" address book as vCard and keep a backup copy. Answer in English.
De-duplicate contacts
Find contacts in the address book that look like duplicates (same name or same phone number), and list the merge candidates so I can confirm. Answer in English.
Create an event
Create an event called "Spring cleaning" in the "Family" calendar for next Saturday at 2 PM, with a reminder one day before. Answer in English.
Review the calendars
List all of my calendars and how many events each one holds, and flag the ones that have not been updated in a long time and could be archived. Answer in English.

Deck and collaboration

Create a board
Create a "Moving plan" board in Deck with three lists, To do / In progress / Done, and add a few cards for the usual tasks. Answer in English.
Review overdue cards
List every overdue, unfinished card in Deck, grouped by board, and remind me to deal with them. Answer in English.
Weekly report
Pull together the cards completed in Deck this week and turn them into a short weekly report. Answer in English.
Document review
List the Office documents that more than one person has edited in the last 30 days, so I can see how collaboration is going. Answer in English.

Troubleshooting and operations

Health check
Run a Nextcloud health check: server version, security and setup warnings, background jobs, storage. Report each item in turn with a recommendation. Answer in English.
Trusted domains
Check the current trusted_domains setting, confirm the public URL is on the list, and if it is not, tell me what to add. Answer in English.
Background jobs
Check whether background jobs (cron) are running properly, find the job that has gone longest without running, and suggest how to handle it. Answer in English.
Storage alert
When overall storage drops below 15%, list the priority order for freeing space (trash bin, duplicate files, users over quota). Answer in English.

FAQ

How do I edit a prompt so it does not touch the whole library by mistake?
Always add two things: "scope", and "report first, then act". For example: "list the number of items this will affect and wait for my confirmation before you run it".
What do I authenticate with?
Always an app password (create one under personal settings → "Security"). Never write your main password into an agent or a script.
Cannot find an API?
Nextcloud's WebDAV, OCS and CalDAV/CardDAV endpoints are in the official developer documentation; versions differ slightly, so have the agent check the docs first.
Can I let the agent delete files directly?
We recommend turning "direct deletion" off and using "move to the trash bin + report" instead, for one more layer of protection.
