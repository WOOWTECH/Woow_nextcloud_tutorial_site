Chapter 20

WebDAV, going further

WebDAV lets you reach Nextcloud straight from your system file manager or a third-party tool, the way you would work with a local folder. By the end of this chapter you'll be able to mount Nextcloud as a drive, or use a tool to move files around automatically.

Access without opening a browser

Besides the browser and the desktop client, Nextcloud also supports WebDAV — a standard protocol for file access. With it you can mount Nextcloud as a drive on your system, or let a backup tool or a script read and write it directly, which suits advanced use and automation.

Chapter task: Find your WebDAV URL, connect to it from your system or a tool, and learn what it is good for in automation.

What WebDAV is

WebDAV is a protocol for "accessing remote files over HTTP". Nextcloud gives every account a WebDAV URL, in a format like this:

https://woowtech-nextcloud.woowtech.io/remote.php/dav/files/你的帳號/
What it is forHow to use it
Mounting it as a driveConnect to WebDAV from your system file manager

Always use an app password: WebDAV asks you to enter a username and password. Use an app password (Chapter 5) rather than your main password; it can be revoked on its own.

Five steps to connect over WebDAV

  1. Get your WebDAV URL

    In Files, open "Settings" at the bottom left, or go to your personal settings, and copy your WebDAV URL.

  2. Create an app password

    In personal settings, go to "Security" and create an app password dedicated to WebDAV.

  3. Mount it on your system

    Windows "Map network drive", macOS Finder "Connect to Server" and the Linux file manager can all connect to a WebDAV URL.

  4. Enter your account and app password

    Log in with your account and the app password you created.

  5. Use it like a local folder

    Once it is mounted, Nextcloud turns into a folder you can drag into, open and delete from directly.

Tools and automation

  • rclone: treat Nextcloud as a remote and run scheduled backups / syncs (Appendix C covers the integration options).
  • Cyberduck / WinSCP: move files by drag and drop in a graphical client.
  • Scripts: call WebDAV with curl or a library to upload / download automatically.
Mounting vs syncing: a WebDAV mount is "direct access to the remote" (it takes no space on the machine, but you have to be online); the desktop client is "two-way sync" (there is a local copy, available offline). Pick the one your need calls for.

Common WebDAV pitfalls

  1. Login fails

    Use an app password rather than your main password; check that the URL is complete and includes the account path.

  2. Slow once mounted

    Every WebDAV operation goes over the network, so a great many small files will be slow. For a large batch move, use the desktop client instead.

  3. Windows will not mount it

    The WebDAV built into Windows has limited support for large files and long paths; rclone or a third-party tool holds up better.

  4. Non-ASCII filenames show as garbage

    Check that the tool is using UTF-8; some older tools support it poorly, so switch tools. Note: any filename outside plain ASCII is affected the same way, accented letters included.

WebDAV FAQ

What is the difference between WebDAV and the desktop client?
WebDAV is direct access to the remote (it takes no space on the machine, but you have to be online); the client is two-way sync (there is a local copy, available offline).
Do I have to use an app password?
We strongly recommend it. Typing your main password in all over the place is risky; an app password can be revoked on its own, which is safer.
Can I use rclone to back up somewhere else?
You can. rclone supports WebDAV, so you can back up what is in Nextcloud to another storage, and the other way round too.
Can I use WebDAV on a phone?
You can, with a file app that supports WebDAV, but for day-to-day use the official app is smoother (Chapter 19).
Is WebDAV safe?
It travels encrypted over HTTPS, so how safe it is comes down to how you manage your passwords. Use an app password and check your connected devices regularly.
