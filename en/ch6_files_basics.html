Chapter 6

Files basics

Files is the core app in Nextcloud. Create a folder, upload, download, rename and move files, and get to know the trash bin. By the end you'll be able to manage your files the way you would on any cloud drive.

Files are the core of your cloud

Whether you go on to use Photos, Calendar or the collaboration apps, files sit underneath all of them. Get comfortable with the basic Files actions first and everything that follows goes smoothly. This chapter is pure groundwork: nothing here puts anything at risk.

Chapter task: create a folder, upload a file, download it, rename it and move it. Anything you delete goes to the trash bin first, so you can restore it.

The Files layout

Click "Files" in the top bar to open the app:

Screen areaWhat is in it
The left-hand listCategories such as All files, Favorites, Recent, Shared and Trash bin
The main area in the middleThe files and subfolders in the folder you are in
The "+" at the topNew: Upload file, New folder, New document
The "⋯" at the end of each rowActions on a single file: share, rename, move, delete, download
Breadcrumbs: the path across the top shows which folder you are in; click a level higher up that path to go back.

Six steps to master the basics

  1. Create a new folder

    Click "+" at the top → "New folder", give it a name (for example "Documents") and create it.

  2. Open the folder and upload

    Click into the folder, then "+" → "Upload file", and pick a file to upload. You can also drag a file straight onto the page (Chapter 7 goes into detail).

  3. Download a file

    Open the "⋯" at the end of the file's row and choose "Download", or click the file name to open it and download from there.

  4. Rename

    "⋯" → "Rename", then press Enter when you are done.

  5. Move or copy

    "⋯" → "Move or copy", then pick the target folder. You can also drag and drop.

  6. Delete and the trash bin

    "⋯" → "Delete". Deleted files go to "Deleted files (trash bin)" on the left, and you can restore them within the expiry window.

Deleting is not permanent: a deleted file goes to the trash bin first, and only disappears for good once the retention period passes or you empty the trash bin by hand. If you delete something by mistake, look in the trash bin first.

A few features you will use right away

  • Favorites: star a file, and you can pull it up later from "Favorites" on the left.
  • The file info panel: click the info icon at the end of a file's row to see its size, when it was modified, its shares and its activity.
  • Sorting: click a column heading (name, size, modified) to switch the sort order.
  • Selecting several: tick several files and move, download or delete them in one go.

Common file pitfalls

  1. A file has vanished

    Check the trash bin, Favorites and search first; it may have been moved to another folder or deleted by mistake.

  2. Renaming fails

    A file name cannot contain special characters, or there is already a file with the same name in that folder. Pick a different name.

  3. Downloading is slow

    Large files and large batches are slow by nature; a multi-file download is packed into a zip, which takes time.

  4. You cannot find a file after moving it

    Use the breadcrumbs or search to get back to the target folder; moving only changes where a file sits, the file is still there.

Files FAQ

Are files in the trash bin cleared automatically?
Yes, according to the retention period configured on the site. You can restore a file within that window, after which it is cleared automatically. You can also empty the trash bin by hand to free up space.
Can I edit documents directly in Nextcloud?
Yes. With the Office app you can edit docx/xlsx online (Chapter 15); text files and Markdown can be edited directly too.
Are there limits on file name length or characters?
Yes. Avoid characters such as / \ : * ? " < > |, and do not make file names too long.
How do I download a whole folder at once?
Open the "⋯" on the folder's row and choose download; it is packed into a zip, and a large folder takes a little time.
Does deleting affect the people I have shared with?
Yes. Delete a file you have shared and the other side loses access to it as well. Check that nobody still needs it before you delete.
