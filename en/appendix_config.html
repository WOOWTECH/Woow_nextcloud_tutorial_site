Appendix B

Settings reference

The Nextcloud settings an admin touches most: trusted domains, upload size, storage, caching and backup. This appendix puts what each one controls, and what to watch out for, into quick reference tables.

A handful of settings matter most

Nextcloud has a lot of settings, but a home or a small team only ever touches a few: trusted domains, the upload limit, storage, caching and backup. Understand those five and you have solved 80% of the settings problems you will ever hit.

Back up before you change settings: get config.php wrong and the whole site can become unreachable. Back up first, and change one thing at a time.

trusted_domains (trusted domains)

The one people trip over most. Nextcloud only accepts connections on the domains in this list, so when you put the site behind your own URL you have to add it here.

'trusted_domains' =>
  array (
    0 => 'localhost',
    1 => 'woowtech-nextcloud.woowtech.io',
  ),
Symptom: "Access through untrusted domain" = this URL is not in the list. Add it in the add-on settings or in config.php.

Raising the upload size limit

  1. Confirm what is happening

    A large file fails to upload and you are told the file is too big: usually the limit is simply too low.

  2. Find the PHP settings

    The limit is set by PHP's upload_max_filesize and post_max_size.

  3. Change it the add-on way

    An HA add-on normally gives you the matching option or config file. Follow the add-on documentation, and do not edit files inside the container directly.

  4. Restart and verify

    Restart the service after the change, then upload a large file again to confirm it took effect.

Backup essentials

  • All three: the database + datadirectory (the files) + config.php.
  • Consistency: turn on maintenance mode before you back up, so the data is not changing halfway through.
  • Verify: run a restore drill regularly — a backup you have never restored does not count.
  • On Home Assistant: pair it with Home Assistant snapshots and an external backup (Appendix C).

Common settings pitfalls

  1. The whole site is unreachable after an edit

    A syntax error in config.php (a missing comma or quote). Restore your backup, or fix the syntax.

  2. Links point at the wrong URL

    Set overwrite.cli.url to match your trusted domain.

  3. A performance warning on Overview

    Set up memory caching (APCu / Redis), and switch background jobs to Cron.

  4. Stuck in maintenance mode

    Someone left maintenance on after an update or a backup. Turn it off and access comes back.

Settings FAQ

Where is config.php?
In Nextcloud's config directory. On an HA add-on it is normally managed through the add-on settings or the matching path, so go by the add-on documentation.
Do I have to restart after changing a setting?
Most config.php changes take effect immediately; settings at the PHP or service layer need a service restart.
Can a standard user change these?
No, these are admin-level settings. For user-level settings see Chapter 5.
How big should the upload limit be?
It depends on what you need — set it higher if you back up video. Set it too high and you also have to watch server memory and timeouts.
What is maintenance mode?
A state that suspends user access so you can update or back up safely. Always turn it off when you are done.
