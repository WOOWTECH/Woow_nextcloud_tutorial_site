Appendix B

設定參數速查

管理員最常碰的幾個 Nextcloud 設定：信任網域、上傳大小、儲存、快取與備份。這份附錄用速查表整理它們的意義與注意事項。

少數幾個設定，影響最大

Nextcloud 設定很多，但家庭／小團隊最常碰的就那幾個：信任網域、上傳上限、儲存、快取、備份。把這幾個弄懂，八成的設定問題都能解。

改設定前先備份：config.php 改錯可能整站進不去。動手前備份，並一次只改一個。

trusted_domains（信任網域）

最常踩的一個。Nextcloud 只接受清單內網域的連線，用自訂網址對外時必須把它加進去。

'trusted_domains' =>
  array (
    0 => 'localhost',
    1 => 'woowtech-nextcloud.woowtech.io',
  ),
症狀：「Access through untrusted domain」＝這個網址沒加進清單。在 add-on 設定或 config.php 補上即可。

關鍵參數速查

設定意義注意
trusted_domains允許存取的網域清單自訂網址一定要加
overwrite.cli.url站台對外基準網址設成你的 https 網址，連結才正確
上傳大小上限單檔可上傳的最大值由 PHP 的 upload_max_filesize／post_max_size 決定
datadirectory檔案實際存放位置備份要包含這個目錄
記憶體快取（APCu／Redis）加速與檔案鎖沒設好概覽會出現效能警告
background jobs背景工作執行方式建議 Cron 模式（第 21 章）
maintenance維護模式開關更新／備份時會用到，完成要關掉

調整上傳大小上限

  1. 確認現況

    上傳大檔失敗、顯示檔案過大，多半是上限太小。

  2. 找 PHP 設定

    上限由 PHP 的 upload_max_filesize 與 post_max_size 決定。

  3. 在 add-on 環境調整

    HA add-on 通常提供對應選項或設定檔，依 add-on 文件調整，不要直接改容器內檔案。

  4. 重啟並驗證

    調整後重啟服務，再試上傳大檔確認生效。

備份要點

  • 三塊都要：資料庫 ＋ datadirectory（檔案）＋ config.php。
  • 一致性：備份時可先開維護模式，避免備到一半資料在變動。
  • 驗證：定期做還原演練，沒還原過的備份不算數。
  • HA 情境：可搭配 Home Assistant 的快照與外部備份（附錄 C）。

設定常見卡關

  1. 改完整站進不去

    config.php 語法錯（少逗號、引號）。還原備份或修正語法。

  2. 連結網址不對

    設定 overwrite.cli.url 與信任網域一致。

  3. 概覽效能警告

    設定記憶體快取（APCu／Redis）、背景工作改 Cron。

  4. 卡在維護模式

    更新／備份後忘了關 maintenance。關掉即可恢復存取。

設定常見問題

config.php 在哪？
在 Nextcloud 的 config 目錄。HA add-on 環境通常透過 add-on 設定或對應路徑管理，依 add-on 文件操作。
改設定要重啟嗎？
多數 config.php 變更即時生效；PHP／服務層的設定要重啟服務。
一般使用者能改這些嗎？
不能，這些是管理員層級設定。使用者層級設定見第 5 章。
上傳上限設多大好？
依需求，影片備份可設大一點；設太大也要注意伺服器記憶體與逾時。
維護模式是什麼？
暫停使用者存取以安全地更新／備份的狀態。完成後務必關閉。
