Chapter 2

Install Nextcloud

Install Nextcloud into Home Assistant, and get to know the initial state it is in once the install is done. By the end of this chapter, you'll know what an add-on is, what it is busy doing while it starts, and what to confirm before you open it for the first time.

Lay the foundation first

Nextcloud is a whole suite of cloud services, and it has to be installed before you can use it. On Home Assistant (HA), the route with the least work is to install it as an add-on: no server, database or certificate to put together yourself, and a few clicks bring it up.

This chapter takes you through installing the add-on, starting it, and understanding what it does in the background while it starts, so you do not mistake "it will not open" for a fault when it is only still initializing.

Chapter task: add the repository, install the add-on, start it, and confirm the status is normal. Logging in and actually using it starts in Chapter 3.

What an add-on is and what it saves you

Think of an add-on as a one-click server bundle. Nextcloud itself needs PHP, a database and a web server; the add-on packs all of that into one container, so you press install and it sets up everything that needs to be there.

What you skipWhat the add-on handles
Installing a databaseA database is built in or already wired up
Configuring a web serverAlready configured inside the container
Handling access from outsidePaired with Cloudflare Tunnel (this site's setup) for secure access from outside
This site's setup: the machine you will be using has already been set up by WoowTech, and its public URL is https://woowtech-nextcloud.woowtech.io. If all you want is to use it, skip the install and go straight to Chapter 3 to log in.

Six steps to install Nextcloud

  1. Open the Apps store in HA

    In the Home Assistant sidebar, find "Settings → Add-ons" and open the Add-on Store.

  2. Add the WoowTech repository

    From the menu at the top right of the store, choose "Repositories", paste in WoowTech's repository URL and add it.

  3. Find the Nextcloud add-on and install it

    Refresh the store, find Nextcloud, open it and press "Install". The first install downloads the container image, which takes a few minutes, so do not close it partway through.

  4. Review the configuration options

    Once it is installed, open the "Configuration" tab and confirm the data directory, the admin username and password, and the other options. Leave the defaults for the first run and adjust them later as you need to.

  5. Start the add-on

    Go back to the "Info" tab and press "Start". The first start initializes the database and Nextcloud, so expect to wait a while.

  6. Confirm the status and the log

    After it starts, open the "Log" tab; a message saying initialization finished means it is ready. Once the status shows running, move on to Chapter 3.

First start takes a while: the first start has to create the database and generate the configuration, which can take several minutes. As long as the log is still moving, it is behaving normally, so do not restart it over and over.

Your public URL and trusted domains

Nextcloud has a security mechanism called trusted_domains (trusted domains): it accepts connections only from the domains on that list. When you expose it on a custom URL (such as woowtech-nextcloud.woowtech.io), that URL has to be added to the trusted domains, or you will see an "Access through untrusted domain" error.

If you see "untrusted domain": nothing is broken. The URL has not been added to the trusted list yet. That is an admin setting (Chapter 22, Appendix B), so ask your admin to handle it and do not edit server files yourself.

Common install pitfalls

  1. The install spinner never stops

    The first container image download is slow by nature, so confirm your network is fine and wait it out. If it really is stuck, check the log for errors.

  2. The status goes back to stopped after starting

    Read the log and find the first error message (usually a configuration problem or a port conflict), fix it, then start it again.

  3. Opening the URL returns untrusted domain

    The URL has not been added to the trusted domains. That is an admin setting; see Chapter 22 and Appendix B.

  4. You cannot find the add-on

    Confirm the repository URL was added correctly and that the store has been refreshed; reload the store page if you have to.

Install FAQ

I only want to use it. Do I have to install it myself?
No. This site's setup has already been installed by WoowTech, so go straight to Chapter 3 and log in. This chapter is for people doing the install themselves.
Does the install take up a lot of space?
Nextcloud itself plus the database takes up some space, but the files you upload later are the main consumer. Confirm the host has enough storage before you install.
Can I install it somewhere other than HA?
Yes. Nextcloud has several official install methods, including Docker and AIO. This guide works through the HA add-on case; for the other methods, go by the official docs.
What should I set up first after installing?
Confirm the admin username and password, the data directory and the public URL (trusted domains). The details are in Chapters 21 and 22 and Appendix B.
Is it normal for the start to take so long?
The first start has to initialize the database and the configuration, so anything within a few minutes is normal. If the log is still moving, do not restart it.
