Appendix A

The Apps store and the apps worth having

Every Nextcloud feature arrives as an App. This appendix shows you how to install, enable and disable them in the Apps store, and rounds up the Apps that homes and small teams get the most out of.

Apps decide what your cloud can do

At its core, Nextcloud is files. Photos, Calendar, Talk and Deck are all Apps. Whatever feature you want, you enable the App that provides it. This appendix is the App management reference and the recommended shortlist for admins.

Who can install: installing, enabling and disabling Apps takes admin permissions (Chapter 21). What a standard user sees depends on which Apps the admin has enabled.

How to use the Apps store

  1. Open the Apps page

    Your avatar at the top right → "Apps" (you need admin). Browse by category down the left.

  2. Find the App

    Use the categories or the search box to find the App you want, and read its description and the versions it works with.

  3. Install or enable

    Click "Download and enable". For an App that already ships with the server, "Enable" is all you need.

  4. Disable or remove

    Disable anything you are not using, and check that nobody depends on it before you remove it.

Check compatibility before you update: before you update an App, look at the Nextcloud versions it says it works with, so an update does not break a feature you rely on.

Common Apps pitfalls

  1. You installed it but it is not in the top bar

    Refresh the page, and check that the App is "Enabled" and not merely "Downloaded".

  2. Installation fails

    Read the error message: it may be a compatibility mismatch, or the server may be missing a package (a PHP module, for example).

  3. Is my data still there after I disable an App

    Disabling usually keeps the data; only removing can clear it. Check before you remove.

  4. A feature broke after an update

    Start with that App's compatibility notes and release notes; if you have to, roll back to the older version or wait for a fix.

Apps FAQ

Are Apps free?
Most of what is in the store is open source and free; a few enterprise features need a license. Read the description before you install.
Is more Apps always better?
No. Every enabled App takes up resources and adds to what you have to maintain. Install only the ones you will really use.
Can a standard user install Apps themselves?
They cannot, that is an admin setting. Just tell your admin what you need.
Does disabling an App affect my data?
Disabling usually keeps the data, and re-enabling brings it back; only removing can clear it, so check before you act.
How do I know whether an App is safe?
Prefer the official store, and Apps that state their compatibility and are actively maintained; be careful with anything of unknown origin.
