Chapter 21

Admin settings

Get to know the admin area: users, storage quotas, Apps and version updates. By the end of this chapter, an admin can create accounts, check on space, manage Apps and understand why background jobs matter. Standard users can skim this one.

This chapter is for admins

Nextcloud is a multi-user platform, so somebody has to create accounts, keep an eye on space, manage Apps and stay on top of updates. This chapter is the practical reference for that person, the admin. Standard users only need the concepts.

Admin actions affect everyone: adding or disabling a user, changing a quota, installing or disabling an App and updating the version all affect the whole site. Check what you are about to affect before you act, and if you are not sure, leave it alone.

What the admin area covers

The admin entry point is "Administration settings" in your avatar menu at the top right. The main areas:

AreaWhat it covers
UsersCreate, disable, groups, quotas, password resets
Basic settingsBackground jobs, email, default language
AppsInstall, enable, disable and update Apps
System / OverviewVersion, security and setup warnings, server status

Six steps to create a new user

  1. Open Administration settings

    Your avatar at the top right → the "Users" page (you need admin permissions).

  2. Add the user

    Click "New user" and fill in the username, display name and password (or let the system email them to set their own).

  3. Set the group and the quota

    Assign a group (family, colleagues) and a storage quota, so a single user cannot fill up all the space.

  4. Decide the role

    Give most people a standard user account; make someone an admin only when you are sure they need it.

  5. Hand over the login details safely

    Send the URL, the account and the password over a private channel, and point them at the security notes in Chapters 3 and 5.

  6. Disable rather than delete

    When someone leaves, disable the account first (the data stays) and delete it only once you are sure it is no longer needed.

Least privilege: default to a standard user account. An admin can change site-wide settings and delete accounts, so handing that out widely is a real risk.

Background jobs and Apps

Background jobs: a lot of what Nextcloud does (scanning files, generating previews, sending notifications, cleaning up) runs on a schedule as a background job. We recommend setting background jobs to "Cron" mode in Basic settings, which gives the best performance and reliability. When background jobs are not running properly you get previews that never update and notifications that arrive late.

Managing Apps: the Apps page is where you install, enable and disable features (Photos, Calendar, Talk, Deck and so on). Check that nobody is using an app before you disable it, and look for compatibility warnings before you update one (Appendix A).

Version updates

  • Before you update, always back up first (the database + the data directory).
  • Read the official release notes, and watch for breaking changes across major versions.
  • Update through the add-on or the official update mechanism, and do not skip versions (for example, do not jump straight from a very old version to the latest).
  • After the update, go to "Overview", read the security and setup warnings, and work through them one at a time.
No backup, no update: "it broke and I only found out after the update" is the most painful place to be. A backup is the precondition for updating.

Common management pitfalls

  1. You cannot find Administration settings

    Your account is not an admin. Check your role, or ask another admin to handle it.

  2. Overview is full of warnings

    Work through them one at a time as prompted (background jobs, memory caching, header settings and the like); most of them link to the official docs.

  3. Previews or search do not update

    Background jobs are not running properly. Switch to Cron mode and check that the schedule is actually running.

  4. Installing an App fails

    It may be a compatibility mismatch, or the server may be missing a package. Read the error message and the App's requirements.

Admin FAQ

Can standard users see the admin area?
They cannot. Only an admin account has "Administration settings" in its avatar menu.
Can I disable an account instead of deleting it?
You can. Disabling stops them logging in but keeps their data, which is safer than deleting outright.
How do I set a quota?
On the Users page, set a storage limit for each account, so a single user cannot fill up all the space.
Which mode should background jobs use?
We recommend Cron, which gives the best performance and reliability. It needs a schedule set up on the host.
Can an update break my data?
Follow the official process, back up first and do not skip versions, and the risk stays manageable. A backup is a hard requirement.
