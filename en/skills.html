Teach your AI agent to tidy up your cloud

A skill is the instruction manual that teaches an AI agent one specific craft. Install a file-management skill and your agent will follow best practice to tidy your files, review your shares and keep an eye on your backups. This handbook collects picked skills, ecosystem tools and an install quick reference (surveyed 2026-08).

What a skill is and why you would install one

Think of a skill as an "SOP manual for an AI": one SKILL.md spells out what task it applies to, what steps to follow, which tools to use and what to watch out for. Once an agent has read it, it can do one more thing, and it does it the same way every time instead of guessing from scratch.

For Nextcloud the common skill scenarios are: bulk file cleanup, reviewing and revoking shares, auditing user quotas, taking stock of backups, and Calendar / Contacts upkeep. Install the matching skill and you only have to give the order — the agent works to the SOP.

How to install one (the 3-minute version)

Prerequisite: your agent has to support skills (for example Pi Agent, Claude Code and others). The idea is the same everywhere: put the skill folder into the skills directory.
  1. Find the skill's GitHub repo and note the URL.
  2. In your agent's skill install panel, paste the repo URL or pick the directory.
  3. After installing, confirm the skill shows up in the available list (or in the system prompt).

Bulk file cleanup

Category: cleanup · triggers WebDAV

Sorts files into folders by rule (date, extension, size), with duplicate detection and a dry-run mode (report first, then act).

Share audit

Category: security · triggers OCS API

Scans every share, flags the risky ones with no password, no expiry or public access, and can bulk-add passwords or revoke them.

User and quota audit

Category: management · OCS Provisioning API

Takes stock of account status, groups and quota usage, and finds accounts that are disabled but still taking up space, or over quota.

Backup and restore drills

Category: operations · database + files

Takes stock of your backup state, produces the restore steps, and plans off-site backup with rclone.

Calendar / Contacts upkeep

Category: cleanup · CalDAV/CardDAV

Compatibility notes

  • Version alignment: the Nextcloud API moves on with each version (this guide is on v33), so a skill that hard-codes an endpoint may need updating after an upgrade.
  • Permissions: most actions need the matching permissions or admin; a skill is only useful if it can get an app password / token.
  • App dependencies: skills for Calendar / Contacts / Deck depend on the matching app already being enabled (Appendix A).

Safety rules

Never let a skill delete anything directly: every action follows "report first → you confirm → then act", and deletions always go to the trash bin first.
Use an app password and never let it out: before you install a third-party skill, check whether it sends passwords or file paths outside. If it is from an unknown source, do not install it.
Dry run first: for a bulk operation, ask the skill for a preview that says "N items will be affected", and let it run only once you have confirmed the preview is correct.

SKILL.md spec reference

If you want to write a Nextcloud skill yourself, the core of it is a single SKILL.md:

---
name: nextcloud-share-auditor
description: Scan Nextcloud shares, flag risky ones and revoke them in bulk, with a dry-run mode
---
# Purpose
Use the OCS API to inventory every share and find the ones with no password, no expiry, or public access.

## Steps
1. Call the OCS Shares API to fetch every share
2. Flag the risky ones and produce a "preview list" (N affected)
3. Only after the user confirms, bulk-add passwords, set expiry dates or disable them
4. Report the results and any exceptions

## Safety
- Never delete a file directly, only change share settings
- Always report the blast radius before a bulk operation
- Always use an app password

For the full spec, see the skill documentation for the agent you are using.

FAQ

What is the difference between a skill, an app and an integration?
An app is "a program with an interface", an integration is "two services wired together", and a skill is the manual that "teaches an AI how to do it" — install one and the agent can carry out the work itself.
Can the wrong skill break my cloud?
It can. That is why the safety rules matter most: install only from sources you trust, always dry run first, send deletions to the trash bin first, and use an app password.
Can I write my own skill?
Yes. Follow the SKILL.md skeleton above and spell out the "Steps" and "Safety" sections clearly.
Which skill is worth installing first?
"Share audit" and "duplicate detection + cleanup" make the biggest difference: they cut your risk and free up space right away.
