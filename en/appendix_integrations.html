Appendix C

外部整合

Nextcloud 不是孤島。這份附錄整理它和 Home Assistant、備份工具與其他服務串接的方向，讓你的雲端成為家中數位基礎設施的一環。

把雲端接進生活自動化

Nextcloud 有開放的 API（WebDAV、OCS）與標準協定（CalDAV／CardDAV），能和 Home Assistant、備份工具、腳本串接。整合得好，檔案、行事曆、通知都能自動流動。

本附錄：介紹整合方向與注意事項，不是逐步安裝教學；實際串接依你用的工具而定。

與 Home Assistant 串接

整合方式能做什麼
行事曆整合把 Nextcloud Calendar（CalDAV）接進 HA，做行程觸發自動化
檔案／WebDAVHA 產生的備份、快照、記錄丟進 Nextcloud 保存
通知用 Nextcloud Talk 當 HA 的通知管道（依整合支援）
同機共存：本站環境 Nextcloud 與 HA 都在同一台，內部互連更快；對外都走 Cloudflare Tunnel，不用各自開埠。

備份與同步工具

  • rclone：把 Nextcloud（WebDAV）當 remote，定期同步到別的儲存（異地備份），或反向把外部資料拉進來。
  • HA 快照／備份：add-on 情境可搭配 HA 的備份機制，一起保護設定與資料。
  • 3-2-1 原則：至少三份、兩種媒介、一份異地。自架雲端也要有第二層備份。
Nextcloud 本身不是備份：它是你的主要儲存，還是要另外備份到別處，才擋得住硬碟壞掉或誤刪。

API 與自動化

介面用途
WebDAV檔案讀寫、掛載、腳本搬檔（第 20 章）
OCS API使用者、分享、capabilities 等管理操作
CalDAV／CardDAV行事曆與聯絡人同步（第 11、12 章）
用 App 密碼：任何自動化串接都用 App 密碼（第 5 章），不要把主密碼寫進腳本或設定檔。

整合常見卡關

  1. HA 接不到行事曆

    確認 CalDAV 網址、帳號與 App 密碼；時區要一致。

  2. rclone 連不上

    用 WebDAV 網址（含帳號路徑）與 App 密碼；確認 https 憑證有效。

  3. 自動化沒觸發

    先手動測 API 是否通，再檢查自動化條件與權限。

  4. 權限不足

    某些操作需要 admin 或特定權限；用對的帳號與 token。

整合常見問題

一定要會寫程式才能整合嗎？
不一定。行事曆／聯絡人同步、rclone 備份多半是設定就好；深度自動化才需要一點腳本。
整合會不會有安全風險？
會，所以一律用 App 密碼、走 HTTPS、給最小權限，並定期檢查已連線裝置。
能把 Nextcloud 當唯一備份嗎？
不建議。它是主儲存，仍要用 rclone 等做第二層異地備份。
HA 和 Nextcloud 要分開兩台嗎？
看資源。同機省事、互連快；分開則互不影響、較好擴充。依需求決定。
OCS API 文件在哪？
在 Nextcloud 開發者文件，包含分享、使用者、capabilities 等端點。
