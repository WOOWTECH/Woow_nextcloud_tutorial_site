Chapter 16

Notes 筆記

Notes 是 Nextcloud 的 Markdown 筆記本。讀完這章，你能寫筆記、分類、跨裝置同步，把零散的想法與清單集中在自己家。

把想法收在一處

購物清單、旅行規劃、會議記錄、隨手靈感——這些筆記散在便利貼、手機備忘、各種 app 裡很難找。Notes 讓你把它們集中在 Nextcloud，跨裝置同步、還是純文字（Markdown），簡單又持久。

本章任務：建一則筆記、用分類整理、了解跨裝置同步。

Markdown 與同步

Notes 的筆記是 Markdown 純文字檔，存在 Files 的一個資料夾（通常是 /Notes）。這代表：

  • 筆記就是檔案，能被備份、分享、用其他工具開。
  • Markdown 用簡單符號排版（# 標題、- 清單、**粗體**）。
  • 跨裝置同步靠手機 Notes app 或直接同步該資料夾。
不會 Markdown 也沒關係：直接打字就是純文字筆記，符號是「想排版時」才用。

五步用起 Notes

  1. 打開 Notes

    從 Apps 選單點「Notes」。左側是筆記清單。

  2. 新增筆記

    按「＋ 新增筆記」，第一行通常會變成標題。

  3. 用 Markdown 排版

    需要時用 # 標題、- 項目、[ ] 待辦 排版，或就打純文字。

  4. 分類

    給筆記設「分類（Category）」，例如「購物」「工作」，左側可依分類篩選。

  5. 跨裝置同步

    手機裝 Notes app 登入同帳號，筆記雙向同步，隨手記隨處看。

幾個好用技巧

  • 釘選：常用筆記釘到最上面。
  • 待辦清單：用 - [ ] 打勾清單，購物、打包很好用。
  • 搜尋：筆記多了用搜尋找關鍵字最快。
  • 就是檔案：在 Files 的 Notes 資料夾也能看到這些 .md 檔，能分享、備份。

Notes 常見卡關

  1. 找不到 Notes

    Notes 是獨立 app，可能未啟用，請管理員在 Apps 商店啟用（第 21 章）。

  2. 手機同步不到

    確認手機 app 登入同一帳號、指到同一個 Notes 資料夾。

  3. Markdown 符號沒生效

    切到預覽模式看排版；編輯模式會顯示原始符號。

  4. 筆記不見了

    到 Files 的 Notes 資料夾與回收桶找；筆記就是檔案。

Notes 常見問題

Notes 和一般文字檔差在哪？
底層就是 Markdown 檔，Notes 只是給它更好的清單、分類與編輯介面。
可以分享筆記嗎？
可以，筆記是檔案，用第 8 章的分享方式分享 .md 檔。
手機要用哪個 app？
Nextcloud Notes 有官方手機 app（iOS／Android），登入同帳號即可。
支援圖片或附件嗎？
Notes 以純文字為主；要放圖片可用 Markdown 連到 Files 裡的圖檔。
筆記有數量上限嗎？
沒有硬限制，受你的儲存空間影響。純文字很小，通常不是問題。
