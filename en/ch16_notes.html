Chapter 16

Notes

Notes is Nextcloud's Markdown notebook. By the end of this chapter, you'll be able to write notes, file them under categories and sync them across your devices, so the ideas and lists that were scattered everywhere live at home instead.

Keep your ideas in one place

Shopping lists, travel plans, meeting notes, the idea you jot down on the spot — notes like these end up spread over sticky notes, your phone's memo app and half a dozen other apps, and then you cannot find them. Notes gathers them in Nextcloud, syncs them across your devices and keeps them as plain text (Markdown), which stays light and long-lived.

Chapter task: create a note, organize your notes with categories, and understand how syncing across devices works.

Markdown and sync

A note in Notes is a Markdown plain-text file, kept in a folder in Files (usually /Notes). That means:

  • A note is a file, so you can back it up, share it and open it with other tools.
  • Markdown formats text with a few plain characters (# for a heading, - for a list, **粗體** for bold).
  • Syncing across devices runs through the Notes mobile app, or by syncing that folder directly.
You do not need to know Markdown: type as you normally would and you get a plain-text note. The characters are there for when you want formatting.

Five steps to start using Notes

  1. Open Notes

    Click "Notes" in the Apps menu. The left-hand list holds your notes.

  2. Create a note

    Click "+ New note". The first line usually becomes the title.

  3. Format with Markdown

    When you need formatting, use # 標題, - 項目 or [ ] 待辦; otherwise type plain text.

  4. Set a category

    Give a note a Category, for example "Shopping" or "Work". The left-hand list can then filter by category.

  5. Sync across devices

    Install the Notes app on your phone and log in with the same account. Your notes sync both ways, so you can write one anywhere and read it anywhere.

A few handy tricks

  • Pin: pin the notes you use often to the top.
  • To-do lists: use - [ ] for a checklist, which works well for shopping and packing.
  • Search: once you have a lot of notes, searching for a keyword is the fastest way to find one.
  • They are files: the same .md files show up in the Notes folder in Files, where you can share or back them up.

Common Notes pitfalls

  1. Notes is nowhere to be found

    Notes is a separate app and may not be enabled. Ask your admin to enable it in the Apps store (Chapter 21).

  2. Your phone will not sync

    Check that the mobile app is logged in with the same account and pointed at the same Notes folder.

  3. The Markdown characters do nothing

    Switch to preview mode to see the formatting; edit mode shows the raw characters.

  4. A note has disappeared

    Look in the Notes folder in Files and in the trash bin. A note is a file.

Notes FAQ

What is the difference between Notes and an ordinary text file?
Underneath, it is a Markdown file. Notes only adds a better list, categories and an editor on top of it.
Can I share a note?
Yes. A note is a file, so share the .md file the way Chapter 8 describes.
Which app should I use on my phone?
Nextcloud Notes has an official mobile app (iOS/Android). Log in with the same account and you are set.
Does it support images or attachments?
Notes is plain text first. To include an image, use Markdown to link to an image file in Files.
Is there a limit on how many notes I can have?
There is no hard limit; your storage quota is what constrains you. Plain text is tiny, so it is rarely an issue.
