Chapter 18

Desktop sync

Install the Nextcloud desktop client and keep a folder on your computer in two-way sync with your cloud. By the end of this chapter, the files on your computer sync to Nextcloud on their own: change one side and the other follows.

Just like a Dropbox folder

Uploading through the browser suits the occasional file. For the volume you handle day to day, the desktop client is the least trouble. Once it is installed your computer has a "sync folder": you save into it the way you always do, it syncs to Nextcloud on its own, and multiple computers stay consistent with each other.

Chapter task: Install the desktop client, log in, choose a sync folder, and learn how conflicts are handled.

A mental model for two-way sync

What you doWhat happens
You add or change a file on the computerIt uploads to Nextcloud on its own
Something changes on the Nextcloud sideIt downloads to the computer on its own
Both sides change the same file at onceA conflict copy appears, both versions kept so you can choose
Virtual files: The client can turn on "Virtual files" mode, where a file shows as a placeholder and is downloaded only when you use it. It saves space on the machine and suits a large library.

Six steps to set up desktop sync

  1. Download the desktop client

    Go to the Nextcloud website, download the Windows / macOS / Linux desktop client and install it.

  2. Enter the server URL

    Open the client and fill in https://woowtech-nextcloud.woowtech.io.

  3. Log in and authorize

    It opens a browser to log in and authorize the client (we recommend an app password, Chapter 5).

  4. Choose the sync folder

    Choose whether to sync the whole account or only some folders, and say where the local folder goes on the computer.

  5. Wait for the first sync

    The first run downloads and uploads the files you already have, which takes time. When it is done the icon turns into a green checkmark.

  6. Day-to-day use

    After that, drop a file into the sync folder or edit it in place and it syncs on its own. The tray icon shows the sync progress.

Deletions sync: Delete a file in the sync folder and it is deleted on the Nextcloud side too (it goes to the trash bin). Think it through before you move a large batch.

Conflicts and selective sync

  • Conflict copy: both sides changed the same file, so the client keeps both (the filename is marked as a conflict) and you decide which one stays.
  • Selective sync: sync only the folders you need; the rest is not downloaded, which saves space.
  • Pause syncing: pause when bandwidth is tight, and pick it up again later.

Common sync pitfalls

  1. Syncing never finishes

    There may be a large file, or a great many small ones. Look at the client's activity list for the item that is stuck; check your space and your network.

  2. A conflict copy appears

    That is the protection working as intended. Open both, compare them, keep the right one and delete the other.

  3. Login fails

    Use an app password rather than your main password; check that the URL is right and the certificate is valid.

  4. Some files do not sync

    A filename with special characters, or a file over the size limit, gets skipped, and the client tells you so.

Desktop sync FAQ

Does it take up a lot of space on my machine?
A full sync takes as much space as the cloud does. Virtual files mode saves a great deal of it, because a file is downloaded only when you use it.
Can I sync only some of the folders?
Yes. Use selective sync and tick only the folders you want.
Can multiple computers sync the same account?
Yes. Several can sync at once, and they stay consistent with each other.
Do files I change while offline get synced?
They do. Once you are back online the client catches up on everything that changed while you were offline.
Can I get back something I deleted by mistake?
You can. A deletion goes to the Nextcloud trash bin, and you can restore it within the retention period (Chapter 6).
