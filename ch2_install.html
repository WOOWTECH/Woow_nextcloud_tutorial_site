第 2 章

安裝 Nextcloud

把 Nextcloud 裝進 Home Assistant，並認識安裝後的初始狀態。讀完這章，你會知道 add-on 是什麼、啟動時在忙什麼，以及第一次開啟前該確認哪些事。

先把地基裝好

Nextcloud 是一整套雲端服務，得先「裝起來」才能用。在 Home Assistant（HA）上，最省事的方式是透過 add-on（附加元件）安裝：不用自己弄伺服器、資料庫、憑證，按幾下就跑起來。

這章帶你把 add-on 裝好、啟動，並理解啟動時它在背景做什麼，避免你以為「怎麼開不起來」其實只是還在初始化。

本章任務：加入套件來源、安裝 add-on、啟動，並確認狀態正常。真正登入使用從第 3 章開始。

add-on 是什麼、幫你省了什麼

add-on 可以想成「一鍵安裝的伺服器套裝」。Nextcloud 本體需要 PHP、資料庫、Web 伺服器，add-on 把這些打包成一個容器，你只要按安裝，它會自動把該裝的都裝好。

你不用自己做的事add-on 幫你處理
裝資料庫內建或連好資料庫
設定 Web 伺服器容器內已設好
處理對外連線搭配 Cloudflare Tunnel（本站環境）從外部安全連入
本站環境：你要用的這台已由 WoowTech 裝好、對外網址是 https://woowtech-nextcloud.woowtech.io。如果只是要「使用」，可以略過安裝、直接看第 3 章登入。

六步把 Nextcloud 裝起來

  1. 打開 HA 的 Apps 商店

    在 Home Assistant 左側選單找到「設定 → 附加元件（Add-ons）」，進入附加元件商店。

  2. 加入 WoowTech 套件來源

    在商店右上角選單選「套件來源（Repositories）」，貼上 WoowTech 的 repository 網址並加入。

  3. 找到 Nextcloud add-on 並安裝

    重新整理商店，找到 Nextcloud，點進去按「安裝」。首次安裝會下載映像檔，需要幾分鐘，別中途關掉。

  4. 檢視設定選項

    安裝後先看「設定（Configuration）」分頁，確認資料目錄、管理員帳密等選項。第一次可以先用預設，之後再依需要調整。

  5. 啟動 add-on

    回到「資訊（Info）」分頁按「啟動（Start）」。第一次啟動會初始化資料庫與 Nextcloud，需要等一段時間。

  6. 確認狀態與日誌

    啟動後看「日誌（Log）」分頁，出現初始化完成的訊息表示就緒。狀態顯示執行中即可進入第 3 章。

初次啟動要有耐心：第一次啟動要建資料庫、產生設定，可能要好幾分鐘。日誌還在跑就代表正常，不要反覆重啟。

對外網址與信任網域

Nextcloud 有一個安全機制叫 trusted_domains（信任網域）：只接受清單內網域的連線。用自訂網址（如 woowtech-nextcloud.woowtech.io）對外時，這個網址必須加進信任網域，否則會看到「Access through untrusted domain」錯誤。

看到「untrusted domain」時：不是壞掉，是這個網址還沒被加進信任清單。這屬於管理員設定（第 22 章、附錄 B），請聯絡管理員處理，不要自行改伺服器檔案。

安裝完成的驗收

檢查項通過條件
add-on 狀態顯示「執行中」
日誌沒有反覆錯誤，出現就緒訊息
開啟網址能看到 Nextcloud 登入頁（第 3 章）

安裝常見卡關

  1. 安裝一直轉圈

    首次下載映像檔本來就慢，確認網路正常、耐心等。真的卡住看日誌有沒有錯誤。

  2. 啟動後狀態變回停止

    看日誌找第一個錯誤訊息（多半是設定或連接埠衝突），修正後再啟動。

  3. 開網址出現 untrusted domain

    網址未加進信任網域，屬管理員設定，見第 22 章、附錄 B。

  4. 找不到 add-on

    確認套件來源網址加對、商店有重新整理；必要時重開商店頁面。

安裝常見問題

我只是要用，需要自己安裝嗎？
不用。本站環境已由 WoowTech 裝好，直接看第 3 章登入即可。這章是給要自己裝的人參考。
安裝會佔很多空間嗎？
Nextcloud 本體加資料庫會佔一些空間，之後上傳的檔案才是主要用量。安裝前確認主機有足夠儲存。
可以裝在非 HA 的環境嗎？
可以，Nextcloud 有官方 Docker、AIO 等多種安裝方式。本教學以 HA add-on 情境為主，其他方式請參考官方文件。
安裝後要先做什麼設定？
先確認管理員帳密、資料目錄與對外網址（信任網域）。細節在第 21、22 章與附錄 B。
啟動很久是正常的嗎？
第一次啟動要初始化資料庫與設定，幾分鐘內都算正常。看日誌還在動就別重啟。
